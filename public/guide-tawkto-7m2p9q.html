🛡️ Guardrail AI + tawk.to

Add AI safety monitoring to your tawk.to chatbot

What This Does

Every AI response from your tawk.to chatbot gets scored by Guardrail. You'll see which answers were safe, which were risky, and which should have been flagged — all in your dashboard.

Step 1: Get Your Guardrail API Key (2 min)

  1. Open: guardrail-mvp-production.up.railway.app/developer.html
  2. Enter your email → you'll get a key like gr_live_abc123...
  3. Save this key — you need it in Step 2

Step 2: Set Up the Webhook in tawk.to (3 min)

  1. Log into your tawk.to dashboard
  2. Go to Administration → Settings → Webhooks
  3. Click Create Webhook
  4. Set the Endpoint URL to:
https://guardrail-mvp-production.up.railway.app/api/tawkto/webhook?key=YOUR_API_KEY

Replace YOUR_API_KEY with your key from Step 1.

  1. Select these events: Chat End, Chat Transcript
  2. Click Save
What happens: After every chat ends, tawk.to sends the conversation to Guardrail. Guardrail scores each AI message and logs the results to your dashboard.

Step 3: Connect AI Assist (Optional — 5 min)

If you're using tawk.to's AI Assist feature, you can connect Guardrail as a Custom Tool so the AI can check its own answers:

  1. Go to Add-ons → AI Assist → Settings
  2. Select your AI agent → Integration / API
  3. Click Add Custom Tool (OpenAPI Server)
  4. Enter this schema URL:
https://guardrail-mvp-production.up.railway.app/api/tawkto/openapi.json
  1. Click Save
What this does: The AI Assist agent can now call Guardrail to check the safety of its own responses before sending them. It will see the confidence score and may adjust its answer.

Step 4: View Your Dashboard

See every scored response at:

👉 guardrail-mvp-production.up.railway.app/developer.html

Enter your API key to see:

  • Total responses scored
  • How many were delivered vs flagged vs escalated
  • Confidence scores and safety signals for each

What Gets Scored

RiskExampleResult
Wrong infoBot gives wrong pricing⚠️ Flagged
Bad adviceBot gives legal/medical advice🔴 Escalated
Made-up factsBot invents a service🔴 Escalated
Good answerBot correctly answers a question✅ Delivered

API Access

You can also score responses directly via API:

curl -X POST https://guardrail-mvp-production.up.railway.app/api/check \
  -H "Content-Type: application/json" \
  -H "X-Guardrail-Key: YOUR_API_KEY" \
  -d '{"text": "AI response to check", "userQuery": "original question"}'
