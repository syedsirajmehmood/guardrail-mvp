How it works

Four steps. Zero trust issues.

Guardrail wraps your existing AI pipeline and adds an intelligence layer between output and user.

01 · INTEGRATE
Drop in the SDK
One script tag or npm install. Works with OpenAI, Anthropic, Gemini, or any LLM.
02 · MONITOR
Score every response
Guardrail analyzes confidence, domain risk, uncertainty language, and hallucination patterns.
03 · DECIDE
Route intelligently
Each response gets a decision: deliver, flag for review, or escalate to a human agent immediately.
04 · LEARN
Get smarter over time
Every decision is logged. Your thresholds tune automatically. Guards improve with every interaction.
Decision Engine

Three outcomes. Clear rules.

Every AI response is scored 0–1 and routed to one of three paths.

✅
Deliver
confidence ≥ 0.75
High confidence. Response is delivered to the end user immediately with no interruption.
⚠️
Flag
0.45 ≤ confidence < 0.75
Uncertain response. Delivered with a disclaimer or held for async human review depending on your config.
🔴
Escalate
confidence < 0.45
High risk. Response is blocked and immediately routed to a human agent with full context.

Quick Start

Three lines of code.

Add Guardrail to any existing AI app in under 60 seconds.

index.html · Browser SDK 
<!-- 1. Load the SDK -->
<script src="http://localhost:3001/sdk/guardrail.js"></script>

<!-- 2. Initialize -->
<script>
  const gr = new Guardrail({
    apiKey:   'YOUR_API_KEY',
    context:  'medical',           // or 'legal', 'financial', 'general'…
    onEscalate: (result) => notifyHuman(result),
    onFlag:     (result) => showDisclaimer(result),
  });

  <!-- 3. Wrap your AI call -->
  const aiResponse = await openai.chat("...");
  const result     = await gr.check(aiResponse, { userId: 'u_123' });

  if (result.decision === 'deliver') {
    showToUser(aiResponse);           // confidence: 0.92
  }
</script>
