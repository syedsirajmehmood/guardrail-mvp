🔑 Setup Guide

You need two keys to use the Chat Demo. Here's what each one is and how to get it.

🤖 Anthropic API Key

This is your personal key from Anthropic (the company that makes Claude). It lets Claude answer your questions. Think of it like a login for the AI — you bring your own account.

💳 Claude uses your Anthropic tokens — you pay Anthropic directly, not us
  1. Go to console.anthropic.com
  2. Sign up for an account (or log in if you already have one)
  3. Click Settings → API Keys → Create Key
  4. Copy the key — it starts with sk-ant-api03-...
  5. Paste it in the chat sidebar under "Anthropic Key"

🛡️ Guardrail API Key

This is your free key from Guardrail. It lets our engine analyze every Claude response for confidence, risk signals, and decide whether to deliver it, flag it for review, or escalate to a human. We sit between you and Claude — we don't generate any AI text or use any tokens.

🛡️ 100% free — no tokens, no charges, ever
  1. Go to the Guardrail home page
  2. Enter your email → click Get Free Key
  3. Copy the key — it starts with gr_live_...
  4. Paste it in the chat sidebar under "Guardrail Key"
