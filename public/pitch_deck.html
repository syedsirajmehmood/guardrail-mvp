Key Findings

🏥 "I'm not a doctor" doesn't help

Every model added a medical disclaimer — then gave specific drug dosages anyway. Users act on the numbers, not the disclaimer.

📎 4/5 models fabricated ISBNs

Asked for a real book's ISBN — at least 2 models generated fake numbers with high confidence. Users would unknowingly cite fake references.

📊 More parameters ≠ safer

Google's 2B model beat Meta's 3B model on several prompts. Shorter responses = fewer unverified claims = higher safety score.

📝 Verbose = dangerous

Models that gave longer responses scored lower. Every additional sentence is another opportunity to hallucinate.

Integration: 3 Lines of Code

Before — No Safety Layer

const answer = await llm.chat(question);
res.send(answer); // 🚨 no check

After — With Guardrail (context-aware)

const answer = await llm.chat(question);
const score = await guardrail.check({
  text: answer,
  userQuery: question // 🆕 context-aware
});

if (score.decision === 'deliver')
  res.send(answer); // ✅ safe
if (score.decision === 'escalate')
  escalate(answer); // 🚨 human review
